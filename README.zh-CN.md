# 数学、计算机与人工智能教程

这是 [Maths, CS & AI Compendium](https://github.com/HenryNdubuaku/maths-cs-ai-compendium) 的简体中文译本。原作由 Henry Ndubuaku 编写，遵循仓库中的 Apache-2.0 许可证。

## 导读

许多教材把好想法埋在密集符号里，略过直觉，默认读者已掌握大量知识；而 AI 等快速发展的领域又很容易过时。本教程从基础讲解数学、计算机科学与人工智能，面向希望真正理解问题的学习者，而非只为考试或面试过关的人。

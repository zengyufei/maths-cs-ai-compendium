# 树

*树是文件系统、数据库、编译器和无数面试题背后的层级数据结构。本节涵盖二叉树、BST、平衡树、Trie、线段树、Fenwick 树和并查集，配合遍历模式、递归思维与难度递进的问题。*

- **树（tree）**是连通无环图，第 13 章。最重要的变体是**二叉树（binary tree）**：每个节点至多有两个子节点，左与右。树无处不在：编译器解析树、浏览器 DOM 树、机器学习决策树和数据库 B 树。

!!! note "大白话"
    树就是有层级、没有绕圈的节点结构；从根往下分支，文件夹和网页 DOM 都是现实例子。

- 树问题的关键洞见是：**大多数树问题用递归解决（most tree problems are solved recursively）**。结构本身就是递归的，一棵树是根与两个子树，因此解法也应如此。掌握“解决左子树、解决右子树、合并”的模式，就能解决大多数树问题。

!!! note "大白话"
    一棵树本身就是“根节点加更小的子树”，所以通常先问左右子树，再把答案合起来。

## 二叉树遍历

- 有四种访问每个节点的标准方式：

    - **中序（Inorder）**，左、根、右：对 BST 按排序顺序访问节点。
    - **前序（Preorder）**，根、左、右：用于序列化和复制树。
    - **后序（Postorder）**，左、右、根：用于删除和计算大小。
    - **层序（Level-order）**，BFS：使用队列逐层访问节点。

!!! note "大白话"
    四种遍历只是访问顺序不同：先根、先左后根、最后根，或一层层横向访问；选哪种取决于题目要什么顺序。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def inorder(root):
    if not root:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)

def preorder(root):
    if not root:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)

def postorder(root):
    if not root:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]

from collections import deque

def level_order(root):
    if not root:
        return []
    result, queue = [], deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
```

- **陷阱**：上面的递归遍历在每步创建新列表，源于 `+` 拼接，因此为 $O(n^2)$。要提高效率，传入结果列表并原地追加：

!!! note "大白话"
    递归本身不一定慢，反复用 `+` 复制列表才是问题；共享一个结果列表追加即可保持线性。

```python
def inorder_efficient(root, result=None):
    if result is None:
        result = []
    if root:
        inorder_efficient(root.left, result)
        result.append(root.val)
        inorder_efficient(root.right, result)
    return result
```

### 简单：二叉树最大深度

```python
def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))
```

- **递归模式**：基例，null → 0；对子节点递归；合并，1 + max。相同模式适用于数十种树问题。

!!! note "大白话"
    空树高度是 0，非空节点高度等于左右高度较大者再加 1。

### 简单：翻转二叉树

```python
def invert_tree(root):
    if not root:
        return None
    root.left, root.right = invert_tree(root.right), invert_tree(root.left)
    return root
```

### 中等：最近公共祖先

- **问题**：找出同时为 $p$ 和 $q$ 祖先的最低节点。

!!! note "大白话"
    最近公共祖先就是两条从根往下的路径第一次汇合的那个节点。

- **模式**：若 $p$ 与 $q$ 均在左子树，LCA 位于左子树；均在右子树则位于右子树；若分开，一个左一个右，当前节点就是 LCA。

!!! note "大白话"
    两个目标在同一边就继续往那边找；一左一右时，当前节点正好是它们最近的共同分叉点。

```python
def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root

    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)

    if left and right:
        return root  # p and q are in different subtrees
    return left if left else right
```

- **陷阱**：该实现假设 $p$ 与 $q$ 均存在于树中。若它们可能不存在，需要额外检查。

!!! note "大白话"
    代码找到“看起来的祖先”不等于两个节点真的都在树里；输入可能缺节点时要额外验证。

### 困难：二叉树最大路径和

- **问题**：找出任意两个节点间路径的最大和，路径不必经过根。

!!! note "大白话"
    最优路径可以在任意节点拐弯，不一定经过根，所以每个节点都可能成为最佳路径的中间点。

```python
def max_path_sum(root):
    best = [float('-inf')]

    def dfs(node):
        if not node:
            return 0
        left = max(dfs(node.left), 0)   # ignore negative paths
        right = max(dfs(node.right), 0)

        # path through this node (possibly as the "bend")
        best[0] = max(best[0], node.val + left + right)

        # return the max gain this node can contribute to its parent
        return node.val + max(left, right)

    dfs(root)
    return best[0]
```

- **关键洞见**：每个节点有两个问题：(1) *经过（through）*该节点的最佳路径是什么，左 + 节点 + 右？(2) 该节点能向其*父节点（parent）*贡献的最佳路径是什么，节点 + max(左，右)，因为路径不能在两层处分叉。混淆二者是最常见错误。

!!! note "大白话"
    对外只能向父节点贡献一条分支，但更新全局答案时可以把左右两边一起接上；这两个值不能混为一谈。

## 二叉搜索树，BST

- **BST** 满足：对每个节点，左子树全部值均小于它，右子树全部值均大于它。这使搜索、插入和删除均为 $O(\log n)$，在树平衡时。

!!! note "大白话"
    BST 像二分查找树：小的往左，大的往右；树不歪时每次都能排除一半方向。

```python
def search_bst(root, target):
    if not root:
        return None
    if target < root.val:
        return search_bst(root.left, target)
    elif target > root.val:
        return search_bst(root.right, target)
    else:
        return root

def insert_bst(root, val):
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = insert_bst(root.left, val)
    else:
        root.right = insert_bst(root.right, val)
    return root
```

- **陷阱**：BST 操作只有树平衡时才是 $O(\log n)$。按排序顺序插入构建的 BST 会退化为链表：每个操作 $O(n)$。这正是 AVL、红黑树等平衡 BST 存在的原因。

!!! note "大白话"
    BST 如果一路向一边长，就从“树”退化成“链表”，平衡树就是专门防止这种极端退化。

### 中等：验证二叉搜索树

```python
def is_valid_bst(root, lo=float('-inf'), hi=float('inf')):
    if not root:
        return True
    if root.val <= lo or root.val >= hi:
        return False
    return (is_valid_bst(root.left, lo, root.val) and
            is_valid_bst(root.right, root.val, hi))
```

- **陷阱**：仅检查 `left.val < root.val < right.val` 是错误的。约束要求左子树*所有*节点都更小，而不只是直接子节点；`lo`/`hi` 边界将该约束向下传递。

!!! note "大白话"
    只看亲生孩子不够，深层后代也必须符合祖先留下的上下界。

### 中等：BST 中第 K 小元素

- **模式**：BST 的中序遍历按排序顺序访问节点，第 $k$ 个访问的节点即答案。

!!! note "大白话"
    BST 中序遍历天然从小到大，数到第 $k$ 个就不用继续排完整棵树。

```python
def kth_smallest(root, k):
    count = [0]
    result = [None]

    def inorder(node):
        if not node or result[0] is not None:
            return
        inorder(node.left)
        count[0] += 1
        if count[0] == k:
            result[0] = node.val
            return
        inorder(node.right)

    inorder(root)
    return result[0]
```

## Trie，前缀树

- **Trie** 逐字符在树中保存字符串。每条边代表一个字符，从根到标记节点的路径代表已保存字符串。无论保存多少字符串，Trie 都以 $O(L)$ 查找，$L$ 为字符串长度。

!!! note "大白话"
    Trie 把相同前缀的单词共用一条路，查找成本主要取决于单词长度，而不是字典里有多少词。

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def search(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end

    def starts_with(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True
```

- **何时使用**：自动补全、拼写检查、文字游戏、IP 路由表。凡是需要基于前缀的操作。

!!! note "大白话"
    只要问题反复问“哪些词以这段开头”，前缀树就能把共享前缀的工作复用起来。

### 困难：单词搜索 II

- **问题**：给定字符棋盘和单词列表，找出可通过遍历相邻单元格组成的全部单词。

!!! note "大白话"
    需要在棋盘上走出很多单词；如果每个词都单独搜索，会重复走相同的前缀。

- **模式**：由单词列表构建 Trie，然后从每个单元格使用 Trie 进行 DFS，提前剪枝，若没有单词以当前前缀开始则停止。

!!! note "大白话"
    先把词表压成共享前缀树，搜索时一旦当前路径不是任何单词的前缀，就立即停止。

- **陷阱**：没有 Trie 时，每个单词都要单独 DFS：$O(w \cdot m \cdot n \cdot 4^L)$。Trie 在单词间共享前缀计算，显著减少工作量。

!!! note "大白话"
    Trie 的价值就是把不同单词的公共开头只搜索一次，避免大量重复 DFS。

## 并查集，不相交集合并

- **并查集（Union-Find）**跟踪不相交集合的集合。两个操作：`find(x)` 返回 $x$ 所在集合的代表元；`union(x, y)` 合并包含 $x$ 与 $y$ 的集合。

!!! note "大白话"
    并查集专门维护“哪些对象已经连在一起”，查询代表元，合并两个集合。

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.count = n  # number of connected components

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # path compression
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False  # already connected
        # union by rank
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        self.count -= 1
        return True
```

- 使用路径压缩和按秩合并后，两种操作的摊销复杂度均为 $O(\alpha(n)) \approx O(1)$，反阿克曼函数，实际近似常数。

!!! note "大白话"
    两个优化会让集合树几乎变平，因此反复查询和合并在实践中几乎是常数时间。

- **何时使用**：连通分量、无向图环检测、Kruskal MST、等价项目分组。

!!! note "大白话"
    当你只关心“是否已经连通、合并后属于哪个组”，而不需要具体路径时，并查集很合适。

### 中等：连通分量数量

```python
def count_components(n, edges):
    uf = UnionFind(n)
    for u, v in edges:
        uf.union(u, v)
    return uf.count
```

### 中等：冗余连接

- **问题**：找出删除后能使图成为树的边，即造成环的边。

!!! note "大白话"
    逐条加边时，哪条边把两个本已连通的点再次连起来，哪条边就是多余成环的边。

- **模式**：逐条处理边。第一个两端点已在同一分量内的边造成环。

!!! note "大白话"
    如果两端已经在同一组，再 union 就闭环；第一次出现这种情况的边就是答案。

```python
def find_redundant(edges):
    uf = UnionFind(len(edges) + 1)
    for u, v in edges:
        if not uf.union(u, v):
            return [u, v]  # already connected → this edge creates a cycle
```

## 线段树与 Fenwick 树

- **线段树（Segment trees）**回答区间查询，子数组上的和、最小值、最大值，并支持点更新，二者均为 $O(\log n)$。

!!! note "大白话"
    线段树把数组区间拆成树形小段，既能快速查一段范围，又能快速更新单个位置。

- **Fenwick 树（Fenwick trees）**，二元索引树，是前缀和查询与点更新更简单、更快的替代方案。它使用巧妙位操作：每个位置保存部分和，覆盖范围由最低置位决定。

!!! note "大白话"
    Fenwick 树专门把前缀和拆成几块保存，用最低位的位运算快速跳到相关块。

```python
class FenwickTree:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i, delta):
        i += 1  # 1-indexed
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)  # add lowest set bit

    def prefix_sum(self, i):
        i += 1
        total = 0
        while i > 0:
            total += self.tree[i]
            i -= i & (-i)  # remove lowest set bit
        return total

    def range_sum(self, l, r):
        return self.prefix_sum(r) - (self.prefix_sum(l - 1) if l > 0 else 0)
```

- **何时使用**：需要带更新的重复区间查询。仅需要前缀和时，优先 Fenwick 树；需要任意区间操作，最小、最大、GCD，时，使用线段树。

!!! note "大白话"
    只查前缀和用 Fenwick 更轻；查询和操作更复杂、范围更灵活时用线段树。

## 常见陷阱汇总

| 陷阱 | 示例 | 修复 |
|---------|---------|-----|
| BST 只检查直接子节点 | `left.val < root.val` 漏掉深层违规 | 传递 `lo`/`hi` 边界 |
| 递归中的 $O(n^2)$ 列表拼接 | `inorder(left) + [val] + inorder(right)` | 追加到共享列表 |
| 忘记基例 | 空树上的无限递归 | `if not root: return` |
| 混淆经过路径与到父节点路径 | 最大路径和：在两层处分叉 | 向父节点返回单分支，单独跟踪双分支 |
| Fenwick 的 1 索引与 0 索引 | 树数组 off-by-one | 入口处始终 `i += 1` |
| 并查集未用路径压缩 | 最坏情形每次 find 为 $O(n)$ | `self.parent[x] = self.find(self.parent[x])` |

!!! note "大白话"
    树题常见错误集中在递归边界、BST 全局约束、索引转换和路径压缩；不要只测一棵规整的小树。

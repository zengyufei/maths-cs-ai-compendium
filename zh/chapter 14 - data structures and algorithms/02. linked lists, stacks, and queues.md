# 链表、栈与队列

*链表、栈和队列是更复杂数据结构的构件。本节说明其工作机制，再通过难度递进的问题建立关键模式：快慢指针、单调栈和基于堆的优先队列，并在每一步说明常见陷阱。*

- 数组提供快速随机访问，却使插入昂贵。**链表（linked lists）**提供快速插入，却没有随机访问。**栈（stacks）**和**队列（queues）**将访问限制到一端或两端，正是这种限制使它们强大：限制可做的事，也就简化了需要思考的事。

## 链表

- **单链表（singly linked list）**是节点链。每个节点保存一个值和指向下一个节点的指针，最后一个节点指向 `null`。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

- **相对数组的优点**：在已知位置插入或删除为 $O(1)$，只需重新指向指针，无需移动元素。

- **缺点**：访问元素 $i$ 需 $O(i)$ 遍历，没有随机访问；缓存局部性差，节点分散在内存中。

- **双向链表（Doubly linked lists）**增加 `prev` 指针，支持向后遍历。它用于 LRU 缓存，常数时间删除任意节点，和浏览器历史记录，前进/后退。

| 操作 | 单向 | 双向 |
|-----------|--------|--------|
| 按索引访问 | $O(n)$ | $O(n)$ |
| 头部插入 | $O(1)$ | $O(1)$ |
| 尾部插入 | $O(n)$ 或 $O(1)$* | $O(1)$ |
| 删除给定节点 | $O(n)$** | $O(1)$ |
| 搜索 | $O(n)$ | $O(n)$ |

*有尾指针时。**需要前驱节点，前驱节点需要遍历。

- **哨兵节点（Sentinel nodes）**，虚拟头/尾节点，简化边界情形。没有虚拟头节点时，在头部插入或删除头节点需要特例代码；有虚拟节点时，每个真实节点都有前驱。

```python
# Without dummy: special case for head deletion
def delete_head(head):
    if not head:
        return None
    return head.next

# With dummy: uniform logic
dummy = ListNode(0)
dummy.next = head
# now every deletion is: prev.next = prev.next.next
```

- **陷阱**：忘记处理空链表，`head is None`，或单元素链表。务必测试这些边界情形。

## 模式：快慢指针，Floyd 算法

- 使用不同速度移动的两个指针检测链表性质。**慢（slow）**指针每次移动一步；**快（fast）**指针每次移动两步。

### 简单：链表环

- **问题**：判断链表是否有环。

- **模式**：若有环，快指针最终会套圈追上慢指针，即二者相遇；若无环，快指针到达 `null`。

```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

- **为什么有效**：若环长为 $c$，快指针每步缩小一个节点的间距。慢指针进入环后，它们必在 $c$ 步内相遇。

- **陷阱**：检查 `fast and fast.next`，而非只检查 `fast.next`。若 `fast` 是 `None`，调用 `fast.next` 会崩溃。

### 中等：寻找链表中点

- **问题**：返回中间节点。

- **模式**：快指针到达末尾时，慢指针正好位于中点。

```python
def find_middle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow  # slow is at the middle (or second middle if even length)
```

### 中等：链表环 II，寻找环起点

- **问题**：返回环开始的节点。

- **模式**：快慢指针相遇后，将其中一个指针重置到头节点；二者均每次移动一步，它们会在环起点相遇。

```python
def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            # reset one pointer to head
            slow = head
            while slow != fast:
                slow = slow.next
                fast = fast.next
            return slow
    return None
```

- **为什么有效**：设头节点至环起点距离为 $a$，环起点至相遇点距离为 $b$。慢指针走了 $a + b$，快指针走了 $2(a + b)$。差值是一整个环：$a + b = c$，c 是环长。因此 $a = c - b$：头节点至环起点的距离，等于相遇点沿环向前至环起点的距离。

### 困难：每 K 个一组翻转链表

- **问题**：翻转链表中每 $k$ 个连续节点。

```python
def reverse_k_group(head, k):
    # check if we have k nodes left
    node = head
    for _ in range(k):
        if not node:
            return head
        node = node.next

    # reverse k nodes
    prev, curr = None, head
    for _ in range(k):
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt

    # head is now the tail of the reversed group
    # recursively process the rest
    head.next = reverse_k_group(curr, k)
    return prev  # prev is the new head of this group
```

- **陷阱**：原地翻转模式，`prev, curr, nxt`，值得记住。画出来：每一步将 `curr.next` 向后指向 `prev`，随后推进三个指针。顺序错误会破坏链表。

## 栈

- **栈（stack）**是 LIFO，后进先出：最近添加的元素最先移除。可以想象一摞盘子。

- 操作包括：`push(x)` 向顶端添加，`pop()` 从顶端移除，`peek()` 查看顶端但不移除，均为 $O(1)$。

- 栈是**递归（recursion）**，调用栈、**表达式求值（expression evaluation）**，中缀转后缀，和**撤销操作（undo operations）**，每次动作压栈、撤销时弹出最后动作，背后的隐式结构。

### 简单：有效括号

- **问题**：给定括号字符串 `()[]{}`，判断括号是否平衡。

- **模式**：将左括号压栈。看到右括号时，检查栈顶是否为匹配的左括号。

```python
def is_valid(s):
    stack = []
    matching = {')': '(', ']': '[', '}': '{'}

    for char in s:
        if char in matching:
            if not stack or stack[-1] != matching[char]:
                return False
            stack.pop()
        else:
            stack.append(char)

    return len(stack) == 0
```

- **陷阱**：忘记最后的 `len(stack) == 0`。字符串 `"((("` 没有不匹配，却仍无效，因为有未闭合括号。

## 模式：单调栈

- **单调栈（monotonic stack）**以排序顺序，递增或递减，维护元素。新元素若破坏顺序，就不断弹出元素直至恢复顺序。

- **何时使用**：问题要求“对每个元素，找到下一个/上一个更大/更小元素”。栈使总复杂度为 $O(n)$，因为每个元素最多压栈和弹栈一次。

### 中等：每日温度

- **问题**：给定每日温度，对每一天找出还要等多少天才会出现更高温度。

- **模式**：使用索引栈。当前温度高于栈顶温度时，弹出栈顶并记录距离。

```python
def daily_temperatures(temperatures):
    n = len(temperatures)
    result = [0] * n
    stack = []  # stack of indices, temperatures in decreasing order

    for i in range(n):
        while stack and temperatures[i] > temperatures[stack[-1]]:
            prev = stack.pop()
            result[prev] = i - prev
        stack.append(i)

    return result
```

- 每个元素压栈一次，最多弹栈一次：总计 $O(n)$。

- **陷阱**：栈中应保存索引，而非值。计算距离需要索引。

### 困难：柱状图中最大的矩形

- **问题**：给定柱高数组，找出最大矩形面积。

- **模式**：对每根柱子，找出其可向左和向右延伸多远，即两侧最近的较矮柱。单调递增栈可高效跟踪这一点。

```python
def largest_rectangle(heights):
    stack = []  # stack of indices, heights in increasing order
    max_area = 0
    heights.append(0)  # sentinel to flush the stack at the end

    for i, h in enumerate(heights):
        start = i
        while stack and stack[-1][1] > h:
            idx, height = stack.pop()
            max_area = max(max_area, height * (i - idx))
            start = idx  # this bar can extend back to where the popped bar started
        stack.append((start, h))

    heights.pop()  # remove sentinel
    return max_area
```

- **陷阱**：`start = idx` 这一行很微妙。弹出高于当前柱的柱子时，当前柱可向后延伸到被弹出柱的起点，因为中间所有柱至少与被弹出柱一样高。缺少此行会得到错误面积。

- **陷阱**：哨兵 `heights.append(0)` 确保处理栈中全部剩余柱子。没有它，从未在右侧遇到较矮柱的柱子会被遗漏。

## 队列

- **队列（queue）**是 FIFO，先进先出：元素从后方加入、从前方移除。可以想象商店的排队队伍。

- **双端队列（deque）**支持两端均为 $O(1)$ 的插入和删除。Python 的 `collections.deque` 是标准实现。

- 队列是**BFS**，广度优先搜索，第 14 章第 4 节、**任务调度（task scheduling）**和**消息传递（message passing）**背后的结构。

### 简单：用栈实现队列

- **问题**：仅使用两个栈实现队列。

- **模式**：一个栈负责压入，另一个栈负责弹出。弹出栈为空时，将全部元素从压入栈转入其中，顺序反转。

```python
class MyQueue:
    def __init__(self):
        self.push_stack = []
        self.pop_stack = []

    def push(self, x):
        self.push_stack.append(x)

    def pop(self):
        if not self.pop_stack:
            while self.push_stack:
                self.pop_stack.append(self.push_stack.pop())
        return self.pop_stack.pop()

    def peek(self):
        if not self.pop_stack:
            while self.push_stack:
                self.pop_stack.append(self.push_stack.pop())
        return self.pop_stack[-1]

    def empty(self):
        return not self.push_stack and not self.pop_stack
```

- 每个操作的摊销成本为 $O(1)$：每个元素在两个栈之间最多移动一次。

## 优先队列与堆

- **优先队列（priority queue）**无论插入顺序如何，都先返回最小，或最大，元素。标准实现是**二叉堆（binary heap）**。

- **最小堆（min-heap）**是完全二叉树，每个父节点均小于其子节点，最小值始终在根部。使用数组存储：节点 $i$ 的子节点位于 $2i + 1$ 和 $2i + 2$。

| 操作 | 时间 |
|-----------|------|
| 插入 | $O(\log n)$ |
| 获取最小值 | $O(1)$ |
| 提取最小值 | $O(\log n)$ |
| 由数组建堆 | $O(n)$ |

- Python 的 `heapq` 模块提供最小堆。最大堆可对数值取负。

```python
import heapq

# Min-heap
h = []
heapq.heappush(h, 5)
heapq.heappush(h, 2)
heapq.heappush(h, 8)
print(heapq.heappop(h))  # 2 (smallest)

# Max-heap trick: negate values
heapq.heappush(h, -10)
print(-heapq.heappop(h))  # 10 (largest)
```

### 中等：数组中的第 K 个最大元素

- **问题**：找出第 k 个最大元素。

- **模式**：维护大小为 $k$ 的最小堆。堆根即第 k 个最大元素。堆中有 $k$ 个元素时，若新元素大于根，替换根。

```python
import heapq

def find_kth_largest(nums, k):
    heap = nums[:k]
    heapq.heapify(heap)  # O(k)

    for num in nums[k:]:
        if num > heap[0]:
            heapq.heapreplace(heap, num)  # pop min, push num: O(log k)

    return heap[0]
```

- $O(n \log k)$ 时间、$O(k)$ 空间。它远好于排序，$O(n \log n)$，当 $k \ll n$ 时。

- **陷阱**：使用大小为 $n$ 的最大堆并弹出 $k$ 次也可行，但更慢：$O(n + k \log n)$。大小为 $k$ 的最小堆才是最优方法。

### 困难：合并 K 个有序链表

- **问题**：将 $k$ 个有序链表合并为一个有序链表。

- **模式**：使用包含每个链表头节点的最小堆。弹出最小节点，将其加入结果，再将其下一个节点压入堆。

```python
import heapq

def merge_k_lists(lists):
    heap = []
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(heap, (lst.val, i, lst))

    dummy = ListNode(0)
    curr = dummy

    while heap:
        val, i, node = heapq.heappop(heap)
        curr.next = node
        curr = curr.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))

    return dummy.next
```

- $O(n \log k)$，其中 $n$ 是节点总数。堆始终至多有 $k$ 个元素。

- **陷阱**：堆元组中的 `i`，索引，是决胜字段。没有它，当值相等时 Python 会尝试比较 `ListNode` 对象，因 `ListNode` 不支持 `<` 而崩溃。索引确保比较有效。

## 常见陷阱汇总

| 陷阱 | 示例 | 修复 |
|---------|---------|-----|
| `fast.next` 上的空指针 | 用 `while fast.next` 检测环 | 检查 `fast and fast.next` |
| 未处理空链表 | 翻转 `None` | 添加 `if not head` 守卫 |
| 栈下溢 | 从空栈弹出 | 检查 `len(stack) > 0` 或 `if stack` |
| 忘记哨兵 | 柱状图遗漏最后柱子 | 追加 0 以清空栈 |
| 堆中缺少决胜字段 | 比较不可比较的对象 | 在堆元组中加入索引 |
| 迭代时修改列表 | 遍历时删除节点 | 使用 prev/curr 模式或虚拟头 |

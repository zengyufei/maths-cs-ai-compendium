*图对关系与连接建模，从社交网络、道路地图到依赖链。本节涵盖表示法、BFS、DFS、最短路径、拓扑排序和连通分量，以及主导图面试题的遍历与寻路模式。*

- 我们在第 12 章，邻接矩阵、拉普拉斯、谱性质，和第 13 章，树、平面性、着色，讲过图论。这里聚焦**算法模式（algorithmic patterns）**：如何在代码中遍历、搜索并优化图。

!!! note "大白话"
    这里不再重点证明图论性质，而是学习写程序时怎样走遍图、找路径、判断依赖。

- 两个基础图算法是 **BFS** 与 **DFS**。几乎每个图问题都归结为其中之一，可能带有修改。掌握它们，就能解决绝大多数图问题。

!!! note "大白话"
    图题最常用的两种走法就是按层扩散的 BFS 和一条路走到底的 DFS，其他算法常是它们的变体。

## 图表示法

- **邻接表（Adjacency list）**：为每个节点保存其邻居列表。空间为 $O(|V| + |E|)$，最适合稀疏图，大多数现实图。

!!! note "大白话"
    邻接表只记录真的存在的边，像每个人只列出自己的朋友，适合边不多的图。

```python
# Undirected graph
graph = {
    0: [1, 2],
    1: [0, 3],
    2: [0, 3],
    3: [1, 2]
}

# From edge list
def build_graph(n, edges):
    graph = {i: [] for i in range(n)}
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)  # omit for directed
    return graph
```

- **邻接矩阵（Adjacency matrix）**：$n \times n$ 矩阵，$A[i][j] = 1$ 当边 $(i, j)$ 存在。空间为 $O(|V|^2)$，最适合稠密图或需要 $O(1)$ 查边的情况。

!!! note "大白话"
    邻接矩阵给每一对节点都预留格子，查一条边很快，但节点多而边少时会浪费大量空间。

- **如何选择**：几乎所有情况使用邻接表。仅当图稠密，$|E| \approx |V|^2$，或需要常数时间检查边是否存在时使用矩阵。

!!! note "大白话"
    大多数真实关系网很稀疏，默认选邻接表；只有边接近全连通或频繁查边时才值得用矩阵。

## 模式：BFS，广度优先搜索

- BFS 使用队列逐**层（level by level）**探索节点，是以下问题的首选算法：
    - **无权（unweighted）**图中的最短路径。
    - 层序遍历。
    - 寻找连通分量。
    - 任何询问“最少步数”的问题。

!!! note "大白话"
    BFS 像水波一圈圈扩散，第一次到达某节点时走的步数一定最少，前提是每条边成本相同。

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])

    while queue:
        node = queue.popleft()
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
```

- **关键（Critical）**：在**入队（enqueuing）**时标记 `visited`，而不是出队时。若在出队时标记，多个前驱会多次将同一节点入队，浪费时间并可能产生错误结果。

!!! note "大白话"
    节点一决定入队就要标记，防止多个邻居趁它还没出队又把它重复塞进队列。

### 简单：岛屿数量

- **问题**：给定由 `'1'`，陆地，和 `'0'`，水，组成的二维网格，统计岛屿数。

!!! note "大白话"
    网格里的一个岛就是一片上下左右相连的陆地；从一块陆地出发走完整片，就数一座岛。

- **模式**：遍历网格。找到 `'1'` 时，用 BFS/DFS 标记全部相连陆地单元格为已访问。每次启动 BFS 就是一座岛屿。

!!! note "大白话"
    外层负责找还没访问的陆地，内层负责把整片连通陆地清掉，因此每启动一次搜索就对应一个新岛。

```python
from collections import deque

def num_islands(grid):
    if not grid:
        return 0

    rows, cols = len(grid), len(grid[0])
    count = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                # BFS to mark entire island
                queue = deque([(r, c)])
                grid[r][c] = '0'  # mark visited
                while queue:
                    cr, cc = queue.popleft()
                    for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                        nr, nc = cr + dr, cc + dc
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == '1':
                            grid[nr][nc] = '0'
                            queue.append((nr, nc))

    return count
```

- **陷阱**：`directions = [(0,1),(0,-1),(1,0),(-1,0)]` 是四连通网格邻居模式，几乎每个网格题都会用到，需记住。对八连通，再加对角线。

!!! note "大白话"
    网格题先确认相邻定义：只算上下左右是四连通，算对角线则是八连通，答案会不同。

- **陷阱**：修改输入网格，`grid[r][c] = '0'`，避免单独的 `visited` 集合。面试中可接受，但要明确其权衡，修改了输入。

!!! note "大白话"
    直接把访问过的陆地改成水能省集合，但会破坏原输入；是否允许要看题目约束。

### 中等：腐烂的橘子

- **问题**：新鲜橘子若相邻于腐烂橘子就会腐烂。返回全部橘子腐烂的最短时间，若不可能则为 -1。

!!! note "大白话"
    所有起初腐烂的橘子会同时扩散，每一分钟向四周传一层，所以这是多个起点一起做 BFS。

- **模式**：多源 BFS。将所有初始腐烂橘子同时放入队列，每层 BFS 代表一个时间步。

!!! note "大白话"
    先把全部源点同时入队，队列的一层就是同一时间发生的扩散，天然得到最短时间。

```python
from collections import deque

def oranges_rotting(grid):
    rows, cols = len(grid), len(grid[0])
    queue = deque()
    fresh = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1

    if fresh == 0:
        return 0

    time = 0
    while queue and fresh > 0:
        time += 1
        for _ in range(len(queue)):
            cr, cc = queue.popleft()
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = cr + dr, cc + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))

    return time if fresh == 0 else -1
```

- **关键洞见**：多源 BFS 同时处理所有源。这给出从*任一（any）*源的最短距离，恰好就是“最后一个新鲜橘子多久腐烂”。

!!! note "大白话"
    每个橘子会被最近的腐烂源最早感染，最后被感染的那个时间就是总答案。

## 模式：DFS，深度优先搜索

- DFS 在回溯前尽可能深入探索。它使用栈，显式栈或递归调用栈，是以下问题的首选：
    - 环检测。
    - 拓扑排序。
    - 连通分量。
    - 回溯/穷举搜索。
    - 有约束的寻路。

!!! note "大白话"
    DFS 先沿一条路尽量深入，再回退换路；它适合需要追踪路径、检测环或穷举分支的问题。

```python
def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### 中等：课程表，环检测

- **问题**：给定 $n$ 门课程和先修关系，判断能否完成所有课程，即没有循环依赖。

!!! note "大白话"
    如果 A 要先学 B、B 又要先学 A，就形成死循环，课程永远无法开始。

- **模式**：检测有向图中的环。使用三种 DFS 状态：未访问、进行中，位于当前 DFS 路径、已完成。

!!! note "大白话"
    三种状态区分“没来过、正在这条路上、已彻底查完”；走回正在路径上的点才是真正的环。

```python
def can_finish(num_courses, prerequisites):
    graph = {i: [] for i in range(num_courses)}
    for course, prereq in prerequisites:
        graph[course].append(prereq)

    # 0 = unvisited, 1 = in-progress, 2 = completed
    state = [0] * num_courses

    def has_cycle(node):
        if state[node] == 1:
            return True   # back edge → cycle
        if state[node] == 2:
            return False  # already fully explored

        state[node] = 1  # mark in-progress
        for neighbour in graph[node]:
            if has_cycle(neighbour):
                return True
        state[node] = 2  # mark completed
        return False

    for course in range(num_courses):
        if has_cycle(course):
            return False
    return True
```

- **为何需要三种状态**：两种状态，已访问/未访问，无法区分“正在探索此节点”与“已完成探索此节点”。发现当前正被探索的节点，状态 = 1，意味着找到环；发现已完全探索的节点，状态 = 2，只是交叉边，不是环。

!!! note "大白话"
    只用“访问过”会把安全的共享依赖误判为环；关键是判断它是否还在当前递归路径上。

### 中等：课程表 II，拓扑排序

- **问题**：返回有效课程顺序，拓扑序。

!!! note "大白话"
    拓扑排序要把有依赖的任务排成一列，保证每门课的前置课都排在前面。

- **模式，Kahn 算法，基于 BFS**：从没有入边，入度 0，的节点开始，处理它们并减少其邻居入度，重复此过程。

!!! note "大白话"
    不依赖任何前置的任务先做，做完后解除后续任务的一项依赖，新的零入度任务再加入队列。

```python
from collections import deque

def find_order(num_courses, prerequisites):
    graph = {i: [] for i in range(num_courses)}
    indegree = [0] * num_courses

    for course, prereq in prerequisites:
        graph[prereq].append(course)
        indegree[course] += 1

    queue = deque([i for i in range(num_courses) if indegree[i] == 0])
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            indegree[neighbour] -= 1
            if indegree[neighbour] == 0:
                queue.append(neighbour)

    return order if len(order) == num_courses else []  # empty = cycle exists
```

- **陷阱**：若结果节点数少于图中节点数，说明存在环，某些节点入度永远不会降为 0。

!!! note "大白话"
    最后还有节点排不进去，不是算法漏了，而是它们互相依赖形成了环。

## 最短路径

### Dijkstra 算法

- 在**非负（non-negative）**带权图中，求从一个源到所有其他节点的最短路径。使用优先队列，最小堆。

!!! note "大白话"
    Dijkstra 每次优先确定当前已知最近的节点，再尝试用它去缩短邻居距离，只适用于边权不为负。

```python
import heapq

def dijkstra(graph, start):
    # graph: {node: [(neighbour, weight), ...]}
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    heap = [(0, start)]

    while heap:
        d, node = heapq.heappop(heap)
        if d > dist[node]:
            continue  # stale entry

        for neighbour, weight in graph[node]:
            new_dist = d + weight
            if new_dist < dist[neighbour]:
                dist[neighbour] = new_dist
                heapq.heappush(heap, (new_dist, neighbour))

    return dist
```

- 使用二叉堆的时间为 $O((|V| + |E|) \log |V|)$。

!!! note "大白话"
    每条边最多触发一次有意义的松弛尝试，堆负责快速挑出当前距离最小的节点。

- **陷阱**：`if d > dist[node]: continue` 这一行不可少。没有它会处理过期堆条目，可能退化为 $O(|V|^2)$。

!!! note "大白话"
    同一个节点可能先以较远距离入堆、后来又以更近距离入堆；取到旧记录时必须跳过。

- **陷阱**：Dijkstra 不适用于负权。边权为负时，贪心假设，节点一旦最终确定，距离就是最优，失效。应使用 Bellman-Ford。

!!! note "大白话"
    负权边可能让已经确定的最短路后来变得更短，破坏 Dijkstra 的贪心前提。

### 困难：网络延迟时间

- **问题**：给定 $n$ 个节点和带权有向边，求信号从源头到全部节点的时间。若并非所有节点可达，返回 -1。

!!! note "大白话"
    先从源头算到每个节点的最短到达时间，所有节点都能到时取其中最大的那个。

```python
def network_delay(times, n, k):
    graph = {i: [] for i in range(1, n + 1)}
    for u, v, w in times:
        graph[u].append((v, w))

    dist = dijkstra(graph, k)
    max_time = max(dist.values())
    return max_time if max_time < float('inf') else -1
```

## 强连通分量

- 在有向图中，**强连通分量（strongly connected component, SCC）**是一个极大节点集合，其中每个节点都能到达其他每个节点。

!!! note "大白话"
    SCC 是有向图里“内部任意两点互相都能到达”的最大团体，团体之间则只能单向流动。

- **Kosaraju 算法**：(1) 在原图上 DFS，记录完成顺序；(2) 转置图，反转全部边；(3) 按完成顺序的逆序在转置图上 DFS。第 3 步的每棵 DFS 树都是一个 SCC。

!!! note "大白话"
    第一次 DFS 决定处理顺序，反转边后按反序搜索，会恰好把能互相到达的节点聚在一起。

- **何时使用**：发现循环依赖、2-SAT、将有向图压缩为 SCC 构成的 DAG。

!!! note "大白话"
    当有向关系内部存在互相依赖时，先缩成 SCC 超节点，复杂图会变成没有环的 DAG，便于继续分析。

## 常见陷阱汇总

| 陷阱 | 示例 | 修复 |
|---------|---------|-----|
| 出队时标记已访问 | 同一节点多次入队 | 入队时标记已访问 |
| 有向图仅用两状态访问标记 | 不能区分回边和交叉边 | 使用未访问/进行中/完成三态 |
| Dijkstra 处理负权 | 最短路径错误 | 使用 Bellman-Ford |
| 忘记 `if d > dist[node]: continue` | 处理过期堆条目 | 当前距离更差时始终跳过 |
| 网格边界检查 | 索引越界 | `0 <= nr < rows and 0 <= nc < cols` |
| 未统计 time=0 边界情形 | 腐烂橘子：没有新鲜橘子 | BFS 前检查 `fresh == 0` |
| 将有向图构建为无向 | 先修关系只有一个方向 | 只向一个方向加边 |

!!! note "大白话"
    图题的主要坑是边方向、访问时机、网格边界和权重条件。先把图模型画对，算法才有意义。
